Plink Plonk! Parent's Guide

Parental Settings Coming soon

This page will let you adjust device-wide settings without needing SSH access or an AI agent. Planned for the first pass:

  • Maximum volume -- a hard ceiling on how loud PlinkPlonk can get, set at the system audio level (not just the volume knob's own 0-100% range) so "100%" on the knob means whatever you've decided is actually the loudest it should ever get.
  • Daily playtime limit -- a maximum number of minutes per day, with 0 meaning no limit. This is device-wide, not per-child: everyone sharing the device shares one daily total.

More settings will likely be added here over time.
