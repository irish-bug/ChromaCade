PlinkPlonk Parent's Guide

PlinkPlonk is a teaching instrument, not a toy piano. Every control is built around helping a small child learn note names, octave equivalence (the same note sounds "the same," just higher or lower), and that sharp/flat are modifications to a note, not different notes entirely. This page explains what everything does.

Explore Mode

This is the mode PlinkPlonk starts in. Press any of the 7 rainbow note buttons to play a note -- the LED ring lights up in that note's color, and more than one button can be held at once for a chord.

Left to right on the panel, they run low to high: C, D, E, F, G, A, B.

The other controls

  • Flat / Natural / Sharp rocker switch (far left) -- a 3-position switch that shifts whatever note(s) are currently held. It's global: it applies to everything held at once, not one note at a time.
  • Octave encoder (far left, next to the rocker) -- turn to shift everything held up or down a full octave. PlinkPlonk covers a full 8 octaves (C0 through C8) -- the entire practical range of a full-size piano.
  • Font/voice encoder (far right) -- turn to cycle through instrument sounds. Currently: Toy Piano (the default), Organ, Piano, Ocarina, Steel Drums, Melodic Tom, Violin, Overdrive, Xylophone, Glockenspiel, and Synth. Adding your own instrument sounds through this page: coming soon
  • Pitch-bend joystick (far right, next to the font encoder) -- push to bend the pitch of whatever's held, up to 4 semitones either direction. It springs back to center (and the pitch snaps back) on release. This is the "sharp/ flat is a modification, not a different note" idea made physical and audible.
  • Volume knob (side panel) -- placed somewhere deliberately a little less convenient to reach, so it's not something that gets bumped constantly mid-play.

The OLED screen

While a note is held, the little screen shows:

  • The note name and any sharp/flat, in large text
  • The current instrument voice
  • The note's frequency in Hz, and separately, how much the pitch-bend joystick is currently shifting it -- shown as its own +/- number rather than folded into the main frequency, so it's clear the bend is modifying the note, not replacing it
  • Current volume, as a percentage

Switching modes

Getting into the menu is deliberately a two-handed, can't-do-it-by-accident gesture -- a toddler sustaining a single held note (completely normal play) won't accidentally trigger it.

  1. Press and hold both encoder push-buttons at once (push straight down on the octave encoder and the font encoder, at the same time -- one hand on each end of the shelf) for about 1.5 seconds. The screen switches to a menu view.
  2. Turn the font encoder to move between options.
  3. Click the font encoder's button (a quick press, not a hold) to select.
  4. To back out of the menu -- or to bail out of a Tutor/Simon session entirely and return to Explore -- hold both encoder push-buttons the same way again.

The menu has five options: Explore, Tutor, Simon, Power Off, and Reboot.

Power Off and Reboot are for shutting the device down or restarting it cleanly, instead of using the power cord's switch (which is fine occasionally, but a proper shutdown is easier on the SD card -- see the note below). Selecting either doesn't do it immediately: it drops into a "Power Off?" / "Reboot?" confirmation screen defaulting to No, so a click while just wandering through the menu can't accidentally power the device off -- turning the encoder to highlight Yes and clicking again is what actually triggers it.

About just flipping the switch: this device already does a fair amount to protect itself from that -- logs and temp files are kept off the SD card, and swap (when it's needed at all) lives in compressed RAM, not on disk. Flipping the switch is a reasonably safe way to turn it off. Using the on-screen Power Off option first is still the better habit when it's convenient, since it guarantees a clean shutdown rather than relying on there simply not being anything mid-write at that exact moment -- but an occasional switch-flip isn't something to worry about.

Tutor Mode

Tutor mode teaches a specific song. Pick one from the menu, and:

  1. PlinkPlonk plays the whole song once by itself -- notes sound through the speaker, and the LED ring lights up in each note's color as it plays, so your child can watch and listen before trying.
  2. Then it's their turn: the ring lights up the color of the next note in the song, and waits -- no timer, no rush -- for them to press the matching button, in any octave.

A wrong press is never a penalty -- it just doesn't advance. The correct color stays lit, there's a gentle sound and light cue, and they try again. Finishing the whole song triggers a little light-and-sound celebration.

Simon Mode

Simon mode is the classic memory game: watch a sequence, then repeat it back. It starts with just one note, and grows by one more note every time your child gets a full round right. A wrong press resets back to round one (unlike Tutor mode, Simon is meant to test recall, not just teach) -- but the very next thing that happens is simply starting over, no scolding, no dead end.

You can pick where the sequence comes from:

  • Random -- the classic version. A fresh random note gets added each round, and it never ends.
  • A famous number (like Pi) -- each digit maps to a note (0=C, 1=D, 2=E, 3=F, 4=G, 5=A, 6=B, then it wraps: 7=C, 8=D, 9=E). Reaching the end of the number's digits is a real win, with the full celebration.
  • Any Tutor song -- instead of showing you the whole tune at once like Tutor mode does, Simon reveals it one note at a time as you clear each round, so it plays out as a growing memory challenge instead of a follow-along lesson.

Every song added to Tutor mode automatically becomes available here too -- there's nothing separate to add for Simon mode.

Keep Going?

Finishing a Tutor song, or a Simon game with a fixed length (a famous number or a Tutor song used as a Simon sequence -- Random mode never ends, so this doesn't come up there), no longer drops straight back to Explore mode by itself. After the finish celebration, the screen and a voice prompt offer two choices:

  • Green button -- keep going. Starts the next song (Tutor) or the next sequence (Simon) right away, no trip back through the menu.
  • Red button -- all done. Returns to Explore mode, same as before.

Both choices are read aloud once, right after the celebration, so your child knows both options exist before picking one -- pressing either button before the voice finishes is ignored rather than acted on early, so there's no rush to catch it mid-sentence.

Power User Notes

For anyone comfortable getting into the device itself, not just this page:

  • Remote access: this device runs Raspberry Pi Connect, which gives remote shell access from anywhere -- not just this WiFi. Sign in with the Raspberry Pi ID account it's linked to.
  • Source code: everything -- firmware, enclosure CAD, hardware docs, even this page -- lives at github.com/irish-bug/ChromaCade.
  • Working with an AI coding agent (Claude Code, or another agent of your choice): the repo has a CLAUDE.md at its root with everything an agent needs to get oriented -- architecture, conventions, what's already been tried and rejected, current hardware state. Clone the repo and start your agent from inside that directory, e.g.:
    git clone git@github.com:irish-bug/ChromaCade.git && cd ChromaCade && claude
    Claude Code (and most similar tools) automatically read a project's CLAUDE.md as context -- no extra flag needed. Working directly on the device over SSH instead? Point your agent at ~/ChromaCade in the SSH user's home directory the same way.
  • Deploying a change: the app runs as a systemd service (chromacade.service), not a script you launch by hand. After pulling new code, run sudo systemctl restart chromacade.service for it to take effect.
